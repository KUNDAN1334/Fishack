To configure the Snowflake Integration in Flowlytics v2.3, specific warehouse, role, and credential requirements must be met before connecting your account. You must provide a dedicated virtual warehouse sized at least X-Small to handle analytical queries generated by the platform. The connecting user role must be granted USAGE on the target warehouse, database, and schema, along with SELECT permissions on all tables and views designated for ingestion. 

For authentication, Flowlytics supports key-pair authentication alongside standard username and password credentials. When utilizing key-pair authentication, ensure your private key is unencrypted and associated with the designated Snowflake user. Flowlytics validates all provided credentials against error code SF_AUTH_FAIL if authentication fails during setup. Verify that network policies on your Snowflake account allow inbound connections from Flowlytics IP ranges before initiating the integration.
