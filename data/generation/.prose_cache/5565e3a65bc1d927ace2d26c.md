The issue occurred because private DNS was not enabled on the VPC endpoint. When private DNS is disabled, the endpoint does not automatically resolve to the AWS PrivateLink service domain names, causing connection attempts from your network to fail. 

To resolve this, navigate to the Amazon VPC console, select your VPC endpoint, and choose Enable private DNS names from the actions menu. If you are managing DNS manually, ensure your internal DNS zone forwards requests to the correct endpoint interface IP addresses. Once private DNS is enabled, allow up to five minutes for propagation before testing the connection to Flowlytics again.
