Flowlytics v2.2 introduces two new formula functions for custom metrics: `PERCENTILE()` and `RATE()`. 

The `PERCENTILE(metric, p)` function computes the exact $p$-th percentile for a given metric stream over the evaluation window, where $p$ is a decimal value between $0.0$ and $1.0$. 

The `RATE(metric, interval)` function calculates the per-second rate of change for a metric across the specified time interval string, such as `1m` or `1h`. Both functions are now available in the metric builder for all enterprise tier accounts.
