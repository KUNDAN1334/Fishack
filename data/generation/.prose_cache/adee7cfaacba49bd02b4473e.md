Flowlytics v2.4 increases the maximum query execution time to 60 seconds, extending the previous limit of 30 seconds. Long-running analytical and billing queries now have additional time to complete before aborting. If a query exceeds the new 60-second threshold, the platform terminates the process and returns the standard error code ERR_TIMEOUT_502. This adjustment accommodates more complex data aggregations and larger datasets across your workspace without requiring immediate query optimization.
