The ERR_INVALID_KEY error occurred because the impacted API key was tied to the personal account of the offboarded employee. When the employee's profile was deactivated, all associated personal tokens were automatically revoked. 

To resolve this issue, a dedicated service key must be generated instead of using individual employee credentials. Service keys remain active independently of personnel changes and prevent unexpected disruptions to your integrations. 

Please navigate to Settings, select API Keys, and generate a new service key for your pipelines. Update your configuration files with this new credential to restore normal operations.
