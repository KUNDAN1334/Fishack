The SAML login loop you experienced occurred because your Identity Provider was sending an unexpected NameID format in the assertion response. Flowlytics strictly requires the NameID format to be set to emailAddress to properly match user accounts and establish a session. Because a different format was received, the authentication handshake failed silently and redirected back to the login page. To resolve this, update your IdP application settings to output the NameID as emailAddress. Once this change was applied on your end, test authentication again. The login loop should now be completely resolved. Please let us know if you encounter any further issues.
