The API key rotation process in Flowlytics involves updating the key across our distributed infrastructure. This propagation can take up to 60 seconds to complete. During this time, the old key may still be cached, causing it to appear as though the new key is not working. If you've recently rotated your API key and it's stopped working, please try retrying the request after a minute. This should allow the system to propagate the new key and resolve the issue. If you continue to experience issues, please let us know and we'll be happy to assist further.
