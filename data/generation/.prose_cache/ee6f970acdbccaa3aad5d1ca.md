With the release of Flowlytics v2.0, all v1 SDKs have officially entered maintenance mode. During this transition period, v1 SDKs will receive critical security patches and bug fixes only, with no new features planned. Users must migrate to the v2 SDK suite prior to the hard sunset date of December 31, 2026. After this date, all v1 endpoints will return error code 410 Gone, and support requests for v1 implementations will be closed. Refer to the v2 Migration Guide for step-by-step upgrade instructions.
