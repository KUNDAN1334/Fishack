Flowlytics v2.2 introduces HMAC-SHA256 signature verification for all outbound webhooks to improve security and prevent request forgery. Each webhook delivery now includes a signature header containing the cryptographic hash of the payload, computed using your endpoint's secret key. 

To verify incoming requests, you must compute the HMAC-SHA256 hash of the raw request body using your webhook secret and compare it securely against the provided signature. Unverified payloads should be rejected immediately.
