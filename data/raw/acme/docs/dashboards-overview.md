# Dashboards Overview


## Creating a Dashboard

The dashboard builder walkthrough is a step-by-step process that guides users through the creation of a customized dashboard on the Dashboards Overview page in analytics, version 2.2. This process begins with selecting a dashboard template, which provides a pre-configured layout and set of widgets to get started quickly.

Users can then add, remove, and rearrange widgets to suit their needs. Available widgets include metrics, charts, and tables, each with its own set of configuration options. The walkthrough also covers how to customize widget settings, such as colors, fonts, and data ranges.

Additionally, users can add filters and parameters to refine their dashboard data and make it more relevant to their business needs. The walkthrough concludes with a preview of the completed dashboard, allowing users to make final adjustments before saving and sharing their custom dashboard with others. This ensures a seamless and intuitive experience for users.


## Widget Types

The Chart Widget Catalog provides a comprehensive list of available chart types that can be added to dashboards in Flowlytics analytics v2.2. This catalog offers flexibility and customization options for users to effectively visualize their data.

The catalog includes the following chart types:
- Line Chart
- Bar Chart
- Pie Chart
- Scatter Plot
- Area Chart
- Column Chart

Each chart type can be further customized with various options, such as changing colors, adding labels, and adjusting data ranges. Users can also apply filters and drill-down capabilities to enhance data exploration and analysis. By utilizing the Chart Widget Catalog, users can create tailored dashboards that meet their specific needs and provide actionable insights into their business performance.

## Sharing and Permissions

The internal sharing feature allows administrators to share dashboards with specific users or groups within their organization. This can be done by clicking the 'Share' button on the top right corner of the dashboard. A modal window will appear, prompting the administrator to select the desired sharing options.

Administrators can choose to share the dashboard with individual users or groups. The 'Viewer' role is available for internal sharing, which grants users read-only access to the dashboard. Users with the 'Viewer' role can view the dashboard but cannot edit or delete any content.

Public links can also be generated for dashboards, allowing external users to access the dashboard. However, public links do not support the 'Viewer' role and users will have full access to the dashboard. This option should be used with caution and only when necessary.
